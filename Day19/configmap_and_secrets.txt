ConfigMap:
    Used to store non-sensitive configuration data such as application settings, URLs, ports, and feature flags.
    Pods can consume ConfigMaps as environmental variables, command-line arhguments, or as confguration files in volumes.


Secrets:
    Used to store sensitive information such as passwords, tokens, API keys, and certificates.

Why do not put them directly in pod?
    To seperate the configuration from application code, improve reusability, simplify updates. and protect sensitive informations. 
    
-----------------------------------------------------------------------------------------------------------------------------------------

Using as environment variable in pod
------------------------------------

    --> Easy for applications that read environment variables. 
    --> Individual keys can be mapped to specific variables.
    --> If the configmap changes, pod will not automatically see the values.
    --> Usually requires pod restart to pickup changes. 

ConfigMap as mount (volumemounts)
---------------------------------

    --> Best for configuration files. 
    --> kubernetes automatically updates mounted files when the configmap changes 
    --> No pod restart required for the updated file content. 
    --> Application must read configuration files.(The application needs to be capable of loading its configuration from a file path, rather than expecting values only from environment variables.)
